# КУРСОВИЙ ПРОЄКТ
# ТЕСТУВАННЯ MERCHANT PAYMENT SERVICE — DOCKER BLACK BOX

Цей репозиторій містить набір автоматизованих інтеграційних тестів (`pytest`), результати чорнового тестування (Black-box testing), тестову стратегію та зафіксовані дефекти для Docker-сервісу мерчанта (`merchant-api:1.1`).

---

## 📁 Структура проєкту

```text
course-project/
│
├── bugs/                      # Знайдені дефекти (Bug Reports)
│   ├── BUG-001-idempotency.md # Порушення механізму ідемпотентності
│   └── BUG-002-over-refund.md # Дозволено овер-рефанд (перевищення суми)
│
├── TEST-STRATEGY.md           # Документ із тест-стратегією проєкту
├── test_payment_service.py    # Набір з 10 автоматизованих тестів (pytest)
├── docker-compose.yml         # Конфігурація Docker (API + PostgreSQL)
└── README.md                  # Інструкція та опис проєкту

## Технологічний стек
* **Мова програмування:** Python 3.x
* **Фреймворк тестування:** `pytest`
* **HTTP-клієнт:** `requests`
* **Контейнеризація:** Docker & Docker Compose
* **База даних:** PostgreSQL

## Детальна інструкція: Як запустити тести локально

Щоб успішно розгорнути тестове середовище та виконати написані автоматизовані тести на вашому комп'ютері, виконайте такі кроки по черзі:

### Крок 1. Передумови
Переконайтеся, що на вашому комп'ютері встановлені:
1. **Docker** та **Docker Compose** (і що сервіс Docker Desktop запущений).
2. **Python** (версії 3.8 або вище) разом із менеджером пакетів `pip`.

### Крок 2. Запуск бекенд-сервісу через Docker
Відкрийте термінал (або командний рядок), перейдіть у кореневу папку проєкту (`course-project`) та виконайте команду для підняття контейнерів у фоновому режимі:
```bash
docker compose up -d
